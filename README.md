One line, under 200 characters: the most creative excuse a hardware wallet gives for refusing to sign a transaction at 3 AM.

> 3 AM? My secure element clocked out at midnight, my PIN pad is dreaming in hex, and I only sign autographs at this hour — never transactions.

`main.ts` (Node 22 stdlib only) writes the line deterministically to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`) and validates the gate: UTF-8 text, 1–200 characters, not only whitespace, single line.
